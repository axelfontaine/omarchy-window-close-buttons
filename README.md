# Window close buttons

As simple as it sounds: an [Omarchy](https://omarchy.org) shell plugin that adds close buttons to windows, enhancing usability and beginner-friendliness without sacrificing esthetics.

Hover over a window's top-right corner and a small close button appears. Simply click it to close the window.

https://github.com/user-attachments/assets/89a5e81f-2f21-4c6a-8aef-272098677c93

It's easily discoverable without visual clutter and it follows the current theme as expected.

## Install

```
omarchy plugin add https://github.com/axelfontaine/omarchy-window-close-buttons.git --enable
```
